AeroTalk Technical Architecture

Bluetooth Microphones

Browsers interact with Bluetooth headsets and speakers through the host Operating System's audio configuration. To connect a Bluetooth microphone:

  1. Pair and connect the Bluetooth device inside your computer's OS settings.
  2. Allow this browser permission to access microphones.
  3. Use the Device Configuration drop-down menu on the left to select your Bluetooth mic.

Web Bluetooth API (BLE)

The Scan BLE Devices feature uses Web Bluetooth API to connect directly to Bluetooth Low Energy smart buttons or peripherals. You can scan for general services and characteristics, making this app ready for custom hardware button triggers.

Serverless WebRTC

This web app uses a serverless signaling protocol. By copy-pasting standard Session Description Protocol (SDP) keys, two different browser tabs/devices can form an encrypted, peer-to-peer real-time audio pipeline without routing voice through any server.

Web Audio FX DSP

Microphone streams are directed through a custom digital signal processing graph including lowpass/highpass filters, wave shapers for distortion, delay nodes, and custom impulse-response nodes.
